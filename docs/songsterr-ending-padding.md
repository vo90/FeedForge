# Short recording-end silence

Implementation branch: `feat/songsterr-ending-padding`; acceptance and runtime:
`integration/songsterr-test`, using the existing shared Songsterr runtime.

## Policy (preservation contract 36)

Prefer the minimum sample-rounded silent suffix, up to two seconds, when every
attack in every arrangement begins before the original recording ends. Only an
already-started note's sustain or gesture may cross that endpoint. Derive the
required duration from the latest playable event, not empty written measures.
Keep all note, bend, slide and other supported gesture times unchanged.

The exact approved revision/recording map must pass structural checks. Require
the existing strict recording-clock assessment across the original audio,
including support in its ending region. Never analyze added silence as evidence.
An inconclusive optional padding check falls back to existing trimming/cutoff
or audio-selection behavior. It does not relax those policies. Negative openings
still require their separate bounded repair; padding cannot authorize them.

Encode from the decoder source once, appending only the necessary zero samples
alongside any minimum two-second preparation prefix. Keep previews musical.
Recheck the actual encoded original recording. Retain original sample count,
rate, duration, decoded identity, padding length and source timing evidence.
The independent raw-source verifier reconstructs eligibility, checks minimal
padding, actual silence, duration, audio identity and original-recording sync.
All evidence lives in the FeedPak and durable evidence store; history displays
the number of ending-silence seconds. No game-side schema changes are required.

## Validation

- Deterministic acoustic fixture: known plucked notes, final held note, bend and
  slide, plus empty trailing bars. Real Vorbis encode and source verification.
- Boundary tests: both zero and two-second edges, late attacks in any part,
  negative attacks, overlong tails, no tail, and inconclusive sync fallback.
- Corrupt output tests: endpoint, duration, frame count, gesture, note, audible
  suffix and forged acoustic success must fail independent verification.
- Retained original-recording replay of the 100-song cohort, plus Highway To Hell.
  Preserve prior evidence; bound disk use by reusing media and discarding only
  scratch generated by this test run after retaining compact evidence/results.
- Full converter and desktop contracts; packaged app import and shared game
  load/playback/seek/render checks. No new game runtime and no physical scoring test.

Silence preserves an existing tail; it cannot reconstruct missing music or prove
every note's timing. Acoustic uncertainty remains explicit and may prevent this
policy from resolving a particular failed song.
