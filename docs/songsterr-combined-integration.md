# Hybrid Lead, chart guidance and recording verification

The combined integration emits preservation contract 40. It includes regional
Hybrid Lead selection revision 4, `feedforge-chart-guidance-v1`, and the opening
and ending checks from contract 39, including explicit bounded ending warnings.
This is an integration of the existing policies, not a new musical selector.

Generate anchors and ordinary handshapes after each original chart is retimed.
When composing Hybrid Lead, discard source-only extension receipts but retain
the guidance ownership proof until its digest is checked. Regenerate guidance
after selection and chord-template remapping, before optional difficulty and
chart/lineage hashes. Independently verify these generated fields against the
completed chart; musical comparisons remain exact.

Worker and desktop acceptance require both requested Hybrid evidence and chart
guidance evidence, bound to the completed archive. Timing summaries and explicit
ending warnings remain available alongside both. Earlier Hybrid and ending
packages retain their independent checks and cannot satisfy a fresh current
request by omitting the new evidence.

This pass targets full imported arrangements with easier-practice generation
disabled. Known optional difficulty/phrase continuity enhancements are outside
this integration, as is the separate compact sustained-repeat renderer. It
requires no additional game or plugin source changes.
